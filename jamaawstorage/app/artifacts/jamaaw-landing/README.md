# JAMAAW Landing Concept

Landing page interativa e independente do aplicativo principal. A peça usa
preto mineral, laranja sólido e papel quente, com três módulos-protagonistas:
Campo, Estoque e Gestão.

## Visualizar

Na pasta `app/`, execute:

```powershell
python -m http.server 4180
```

Depois abra:

```text
http://127.0.0.1:4180/artifacts/jamaaw-landing/
```

Os arquivos são HTML, CSS e JavaScript puros e podem ser publicados como uma
página estática independente.
